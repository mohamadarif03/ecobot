# ecobot

ECOBOT — Platform & Game Edukasi Lingkungan 3D untuk Anak (Petualangan Kota Bersih)

## Fitur Utama
- **Landing Page Interaktif**: 3D Suspension Rail Fakta Sampah, Kenalan Ecobot, Panduan Kontrol Responsif, Preview Dunia 3D Blocky, Doodle Crew Footer.
- **Dashboard Edukasi ECOBOT** (`/beranda`): Profil Pemain, Level & XP Gamifikasi, Meter Kebersihan Kota, Misi Harian, Fakta Lingkungan Harian, Pustaka Edukasi, Kuis & Tantangan.
- **Dukungan Perangkat**: Desain responsif untuk PC (WASD/Keyboard) dan Layar Sentuh Mobile/Tablet.

## Cara Menjalankan
```bash
npm install
npm run dev
```

## Build Produksi
```bash
npm run build
```
